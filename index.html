How to upload the Excel sales report

Follow these steps in ERPNext to download the correct report for this dashboard.

  1. Open ERPNextLog in to your ERPNext account.
  2. Go to Custom ReportsOpen the Custom Reports section in ERPNext.
  3. Open “Stock Report by Item & SKU”Select this report and set the date range you want to analyse.
  4. Export as ExcelUse the report’s Export option and choose Excel format (.xlsx).
  5. Upload that downloaded file hereReturn to this dashboard, click Upload Excel report, and select the .xlsx file you just exported.
Important: Upload the original ERPNext Excel export without editing or cleaning its columns. The dashboard reads the file in your browser and recalculates the charts and KPIs.
